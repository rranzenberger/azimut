# Decisões de projeto — Empathy Engine

Registro de decisões definitivas para que análises e implementações futuras as respeitem.

---

## Fonte do nome do jogo e títulos

**Decisão (definitiva):** O nome do jogo e os títulos **permanecem com a fonte atual (Syne)**. Não trocar para Handel Gothic (ou outra fonte) a menos que o usuário peça **explicitamente** — e nesse caso o assistente deve **advertir** que o usuário havia pedido para o nome do jogo ficar com a fonte que está (Syne).

- **Fonte em uso:** Syne (`--font-display`) para títulos e nome do jogo.
- **Handel Gothic:** Descartado definitivamente. Não sugerir em análises futuras; não implementar a menos que o usuário peça explicitamente, com advertência acima.

---

## Power-up Duplicar carta

**Decisão:** Power-up **"Duplicar carta"** (usar a mesma carta 2× na zona) fica **opcional para versão 1.2**. Não implementar na 1.1; em análises futuras tratar como candidato a v1.2 apenas.
