# Backoffice Azimut

Código do backoffice (admin, leads, Neon, APIs).

**No Vercel:** este código é deployado no **projeto azimut-backoffice** (domínio backoffice.azmt.com.br). O nome da pasta no repo é `azimut-cms`; o projeto no Vercel é **azimut-backoffice**.

- Configurações, variáveis e deploy: use sempre o projeto **azimut-backoffice** no Vercel.
- Ver: [docs/DEPLOY_BACKOFFICE_VERCEL.md](../docs/DEPLOY_BACKOFFICE_VERCEL.md) e [docs/PROJETOS_VERCEL.md](../docs/PROJETOS_VERCEL.md).
