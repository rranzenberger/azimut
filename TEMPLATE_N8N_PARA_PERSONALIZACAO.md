# 🎯 Qual Template n8n para Personalização de Emails?

## ✅ IMPORTANTE: O Template Não Faz a Personalização!

**O template n8n é só a "plataforma".** A personalização vem do **workflow** que vamos criar depois!

---

## ✅ QUALQUER TEMPLATE BÁSICO SERVE!

Para o seu objetivo (captar dados, identificar, personalizar emails), **qualquer template n8n com PostgreSQL funciona!**

### Opções que Funcionam:

1. **"n8n (w/ postgres)"** ✅
2. **"n8n+postgres"** ✅
3. **"Simple N8N"** ✅
4. **Qualquer outro com postgres** ✅

**Todos fazem a mesma coisa:** Rodam o n8n com banco de dados.

---

## 🎯 O QUE FAZ A PERSONALIZAÇÃO:

### 1. Workflow no n8n (vamos criar depois)
- Recebe lead do site
- Chama SerpAPI (pesquisa sobre a pessoa/empresa)
- Chama Claude AI (analisa e gera email personalizado)
- Envia via Resend

### 2. Claude AI (já temos a API key)
- Analisa dados do lead
- Identifica interesses, hobbies, empresa
- Gera email com small talk
- Torna empático e simpático
- Cria sensação de parceria

### 3. As 3 API Keys (já temos)
- SerpAPI: pesquisa dados
- Claude: gera email personalizado
- Resend: envia email

## 📋 RECOMENDAÇÃO FINAL:
