# 📊 Como Monitorar Google Search Console

## 🎯 OBJETIVO

Acompanhar o desempenho do site no Google semanalmente.

---

## 📋 O QUE VERIFICAR (Semanalmente)

### **1. Indexação (Menu: Indexação → Páginas)**

**O que verificar:**
- Quantas páginas foram indexadas
- Quantas páginas não foram indexadas
- Motivos de não indexação

**Como verificar:**
1. Menu lateral → **"Indexação"** → **"Páginas"**
2. Veja o gráfico:
   - Linha verde = Páginas indexadas ✅
   - Linha cinza = Páginas não indexadas ⚠️
3. Clique em páginas não indexadas para ver o motivo

**O que fazer:**
- Se houver erros → Corrigir
- Se houver páginas duplicadas → Adicionar canonical
- Se houver 404 → Corrigir URLs

---

### **2. Desempenho (Menu: Desempenho)**

**O que verificar:**
- Quantas pessoas encontraram seu site
- Quais palavras-chave
- Quais páginas aparecem mais
- Taxa de cliques (CTR)
- Posição média

**Como verificar:**
1. Menu lateral → **"Desempenho"**
2. Veja o gráfico de cliques e impressões
3. Veja a tabela com palavras-chave
4. Veja a tabela com páginas

**O que fazer:**
- Identificar palavras-chave com mais cliques
- Otimizar páginas que aparecem mas não recebem cliques
- Melhorar CTR (títulos e descrições)

---

### **3. Cobertura (Menu: Indexação → Cobertura)**

**O que verificar:**
- Páginas válidas
- Páginas com erros
- Páginas excluídas

**Como verificar:**
1. Menu lateral → **"Indexação"** → **"Cobertura"**
2. Veja o gráfico de status
3. Clique em cada categoria para ver detalhes

**O que fazer:**
- Corrigir erros rapidamente
- Resolver páginas excluídas
- Manter páginas válidas

---

### **4. Core Web Vitals (Menu: Experiência → Core Web Vitals)**

**O que verificar:**
- LCP (Largest Contentful Paint)
- INP (Interaction to Next Paint)
- CLS (Cumulative Layout Shift)

**Como verificar:**
1. Menu lateral → **"Experiência"** → **"Core Web Vitals"**
2. Veja se está "Boa" (verde) ou "Precisa melhorar" (amarelo/vermelho)

**O que fazer:**
- Se estiver ruim → Otimizar imagens, código, etc.
- Manter sempre "Boa" para melhor ranking

---

## 📅 ROTINA SEMANAL (5 minutos)

**Toda segunda-feira:**

1. **Indexação** (2 min)
   - Ver quantas páginas indexadas
   - Verificar erros

2. **Desempenho** (2 min)
   - Ver cliques e impressões
   - Ver palavras-chave principais

3. **Cobertura** (1 min)
   - Verificar se há novos erros

**Total:** ~5 minutos por semana

---

## 🚨 ALERTAS IMPORTANTES

**Verifique imediatamente se:**
- Número de páginas indexadas caiu drasticamente
- Aparecer erro crítico (500, 404 em massa)
- Core Web Vitals ficar ruim
- Penalidade do Google (muito raro)

---

## 📊 MÉTRICAS PARA ACOMPANHAR

### **Mensalmente:**

- **Páginas indexadas:** Deve aumentar
- **Impressões:** Deve aumentar
- **Cliques:** Deve aumentar
- **CTR:** Deve melhorar (mais cliques por impressão)
- **Posição média:** Deve melhorar (números menores = melhor)

## 🎯 COMEÇAR AGORA

1. Acesse: https://search.google.com/search-console
2. Vá em "Indexação" → "Páginas"
3. Veja quantas páginas foram indexadas
4. Veja se há erros
5. Anote os números para comparar na próxima semana

**Tempo:** 5 minutos

---

## 💡 DICA

**Configure alertas por email:**
1. No Google Search Console, vá em **"Configurações"**
2. Configure alertas por email
3. Receba notificações quando houver problemas
