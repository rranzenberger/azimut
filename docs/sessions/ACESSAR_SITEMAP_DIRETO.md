# 🔗 ACESSAR SITEMAP DIRETAMENTE

Se não conseguir encontrar "Sitemaps" no menu, acesse diretamente:

## **URL Direta:**

```
https://search.google.com/search-console/sitemaps?resource_id=sc-domain%3Aazmt.com.br
```

**Ou:**

1. Acesse: https://search.google.com/search-console
2. Selecione a propriedade: `http://www.azmt.com.br/`
3. Na barra de endereço, adicione ao final: `/sitemaps`
4. Pressione Enter

---

## **Método Alternativo: Via Inspeção de URL**

Se ainda não conseguir acessar Sitemaps, você pode submeter URLs individualmente:

1. Use o campo **"Inspecionar qualquer URL..."** no topo
2. Digite: `https://azmt.com.br/sitemap.xml`
3. Pressione Enter
4. Clique em **"Solicitar indexação"**

Isso fará o Google descobrir o sitemap automaticamente.

---

## **Verificar se Sitemap Existe:**

Antes de submeter, verifique se o sitemap está acessível:

Acesse no navegador:
```
https://azmt.com.br/sitemap.xml
```

Se abrir e mostrar XML, está OK! ✅
