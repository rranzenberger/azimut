# 🚀 Como Executar Otimização de SEO com IA

## 📍 MÉTODO MAIS FÁCIL (Duplo Clique)

1. Abra o **Explorador de Arquivos**
2. Vá até: `C:\Users\ranz\Documents\azimut-site-vite-tailwind`
3. **Duplo clique** no arquivo: `EXECUTAR_OTIMIZAR_SEO.ps1`
4. Se aparecer aviso, clique em "Executar"

**Pronto!** O script vai executar automaticamente.

---

## 💻 MÉTODO MANUAL (PowerShell)

### **Passo 1: Abrir PowerShell**

- Pressione **Windows + X**
- Escolha **"Windows PowerShell"** ou **"Terminal"**

---

### **Passo 2: Ir para a Pasta**

Digite:

```powershell
cd C:\Users\ranz\Documents\azimut-site-vite-tailwind\azimut-cms
```

Pressione **Enter**

---

### **Passo 3: Executar o Script**

Digite:

```powershell
npx tsx scripts/otimizar-projetos-seo.ts
```

Pressione **Enter**

---

## 📋 COMANDOS COMPLETOS (Copiar e Colar)


## ⚠️ SE DER ERRO

### **Erro: "npx não encontrado"**

Instale Node.js:
- Baixe em: https://nodejs.org
- Instale e reinicie o PowerShell

### **Erro: "ANTHROPIC_API_KEY não configurada"**

Configure a variável de ambiente:
- No Vercel: Settings → Environment Variables
- Adicione: `ANTHROPIC_API_KEY` = sua chave
