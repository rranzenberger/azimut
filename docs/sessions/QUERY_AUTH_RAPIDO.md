# 🔑 QUERY AUTH - Preenchimento Rápido

## 📋 PREENCHER AGORA:

### Campo 1: **Name**
```
SerpAPI Key
```

### Campo 2: **Value**
Cole sua API Key do SerpAPI aqui (a chave direta, não variável)

### Campo 3: **Allowed HTTP Request Domains**
Deixe como **"All"**

### Depois:
Clique em **"Save"** (botão vermelho)
