# 🚀 Como Executar - Versão Simples

## ✅ MÉTODO MAIS FÁCIL

1. Abra o **Explorador de Arquivos**
2. Vá até: `C:\Users\ranz\Documents\azimut-site-vite-tailwind`
3. **Duplo clique** no arquivo: `EXECUTAR_OTIMIZAR_SEO.bat`
4. **Pronto!** Vai executar automaticamente

---

## 💻 MÉTODO ALTERNATIVO (PowerShell)

Se o `.bat` não funcionar:

1. **Clique direito** no arquivo `EXECUTAR_OTIMIZAR_SEO.ps1`
2. Escolha **"Executar com PowerShell"**
3. Se aparecer aviso, clique em **"Sim"** ou **"Executar"**

---
