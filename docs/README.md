# 📚 Documentação do Projeto Azimut

Esta pasta contém toda a documentação do projeto, organizada por categoria.

## 📁 Estrutura

- **deploy/** - Documentação e scripts relacionados a deploy
- **guias/** - Guias, tutoriais e instruções passo a passo
- **checkpoints/** - Checkpoints de progresso e status do projeto
- **resumos/** - Resumos executivos e relatórios
- **auditorias/** - Auditorias completas do site e código
- **workflows/** - Documentação de workflows e automações (N8N)
- **sql/** - Documentação relacionada a SQL e banco de dados

## 🔍 Como Encontrar Documentação

- **Deploy:** `docs/deploy/`
- **Guias:** `docs/guias/`
- **Status do Projeto:** `docs/checkpoints/`
- **Relatórios:** `docs/resumos/`

## 📝 Nota

Esta estrutura foi criada para organizar os 800+ arquivos de documentação que estavam na raiz do projeto.
