# 🎯 PASSO A PASSO SIMPLES: Configurar Bing

## ⚠️ IMPORTANTE: Faça UM passo de cada vez!

---

## 📋 PASSO 1: Abrir Bing Webmaster Tools

1. Abra seu navegador
2. Acesse: **https://www.bing.com/webmasters**
3. Faça login com sua conta Microsoft (ou crie uma se não tiver)
4. **PARE AQUI** e me avise quando terminar

---

## 📋 PASSO 2: Adicionar Site

1. Na página do Bing Webmaster Tools
2. Procure botão: **"Adicionar site"** ou **"Add a site"**
3. Clique nele
4. Digite: `https://azmt.com.br`
5. Clique em **"Adicionar"** ou **"Add"**
6. **PARE AQUI** e me avise quando terminar

---

## 📋 PASSO 3: Escolher Método de Verificação

1. O Bing vai pedir para verificar que você é dono do site
2. Escolha: **"Meta tag"** (é o mais fácil)
3. **Copie o código** que aparece (exemplo: `ABC123XYZ789...`)
4. **PARE AQUI** e me envie o código que você copiou

---

## 📋 PASSO 4: Adicionar Código no index.html

**EU VOU FAZER ISSO POR VOCÊ!**

Me envie o código do Bing e eu adiciono automaticamente no `index.html`!

---

## 📋 PASSO 5: Aguardar Deploy

1. Eu vou fazer commit e push
2. Aguarde 2-3 minutos para o Vercel fazer deploy
3. **PARE AQUI** e me avise quando passaram 3 minutos

---

## 📋 PASSO 6: Verificar no Bing

1. Volte ao Bing Webmaster Tools
2. Clique em **"Verificar"** ou **"Verify"**
3. Aguarde alguns segundos
4. Deve aparecer: ✅ **"Verificado"** ou **"Verified"**
5. **PARE AQUI** e me avise o resultado

---

## 📋 PASSO 7: Submeter Sitemap

1. No Bing Webmaster Tools, procure: **"Sitemaps"**
2. Clique em **"Enviar Sitemap"** ou **"Submit Sitemap"**
3. Digite: `sitemap.xml`
4. Clique em **"Enviar"** ou **"Submit"**
5. **PRONTO!** ✅
